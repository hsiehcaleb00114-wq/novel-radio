# 小說電台 Novel Radio

把網路小說變成背景廣播：貼上小說網址，它會用自然的語音一句一句念給你聽，念完自動接下一頁、下一章，可以邊做事邊聽。

- 🎙️ **Edge 自然語音**：HsiaoChen、HsiaoYu、YunJhe 等 14 種中文聲音（台灣、中國、香港粵語）
- 📖 **貼網址就能聽**：大部分小說網站的章節或書的網址都能直接讀
- ⏭️ **自動接續**：念完一頁接下一頁，念完一章接下一章，會記住每本書聽到哪一句
- 🖼️ **插圖**：內文裡的插圖會顯示出來，點一下全螢幕看
- 🌙 **睡眠定時**：15～90 分鐘後停止，或念完這一章就停
- ⌨️ **鍵盤和媒體鍵**：空白鍵播放／暫停，鍵盤上的播放鍵也能控制
- 🪟 **獨立視窗**：不用開瀏覽器，像一般的電腦程式

> 目前只支援 **Windows 10 / 11**。

## 安裝

### 方法一：下載 exe（最簡單，不用裝 Python）

1. 到 [Releases](../../releases) 下載最新的 `NovelRadio-windows.zip`。
2. 解壓縮到任何資料夾，例如 `D:\小說電台`。
3. 雙擊 `小說電台.exe`。

> Windows 第一次可能會跳出「Windows 已保護您的電腦」，這是因為程式沒有付費的數位簽章。按「其他資訊」→「仍要執行」即可。
>
> `小說電台.exe` 要跟 `reader.html`、`assets` 資料夾放在一起，不要只把 exe 拿出來。

### 方法二：從原始碼執行

1. 安裝 [Python 3.10 以上](https://www.python.org/downloads/)。安裝時記得勾選 **Add Python to PATH**。
2. 下載這個專案：按右上角綠色的 **Code** → **Download ZIP** 後解壓縮，或用 git：

   ```bash
   git clone https://github.com/hsiehcaleb00114-wq/novel-radio.git
   ```

3. 雙擊 `啟動小說電台.bat`。第一次會自動安裝需要的套件（`edge-tts`、`pywebview`），裝完就會打開程式。

想用瀏覽器開也可以：雙擊 `用瀏覽器開啟.bat`，然後到 `http://127.0.0.1:8765`。

## 使用教學

### 1. 開啟小說

在左上角的輸入框貼上網址，按「**開始**」。

| 貼什麼網址 | 會發生什麼 |
|---|---|
| 某一章的網址 | 從這一章開始 |
| 書的首頁或目錄頁網址 | 聽過的書會接著上次的地方，沒聽過的從第一章開始 |

### 2. 播放

按下方中間的大播放鍵就會開始念。

- 正在念的句子會反白，畫面會自動捲到那裡。
- **點任何一句**，就從那一句開始念。
- 點下方的刻度盤可以跳到這一頁的任一位置。
- ⏮ ⏭ 是上一頁／下一頁，◀◀ ▶▶ 是上一句／下一句。

### 3. 朗讀設定

點播放器右下角顯示語速的按鈕（例如 `1.0×`）：

| 設定 | 說明 |
|---|---|
| 聲音 | 最上面一組是 Edge 自然語音（推薦），下面是瀏覽器內建語音 |
| 語速 | 0.5×～3×，也有 0.8×、1×、1.25×、1.5×、2× 快速按鈕 |
| 音量、音調 | 調整後馬上生效 |
| 睡眠定時 | 幾分鐘後停止，或念完這一章停止 |
| 念完自動播下一章 | 預設開啟；關掉的話念完一章會停下來 |
| 顯示插圖 | 只想專心聽可以關掉 |

### 4. 目錄和最近在聽

- 左側「**目錄**」列出整本書的章節，點一下就切換。
- 「**最近在聽**」記住每本書聽到哪一句，點一下接著聽。
- 左上角 ☰ 可以收起側邊欄，只留閱讀區。

### 5. 插圖

- 內文裡的插圖會照原本的位置顯示，**點一下全螢幕看**，`←` `→` 換圖，`Esc` 關閉。
- linovelib 的書可以按播放器上的「**插圖**」，一次看整卷的插圖，**朗讀不會中斷，也不會換章**。

### 6. 其他

- 右上角「**原網頁**」用瀏覽器打開目前這一頁的原網站。
- `A−` / `A+` 調整字體大小。

### 快捷鍵

| 按鍵 | 功能 |
|---|---|
| `空白鍵` | 播放／暫停 |
| `←` `→` | 上一句／下一句 |
| `Esc` | 關閉設定、插圖 |
| 鍵盤媒體鍵 | 播放／暫停、上一頁／下一頁 |

## 支援的網站

小說電台有兩種讀法：

- **專用讀法**：`tw.linovelib.com`，支援整卷插圖集。
- **通用閱讀模式**：其他網站。像瀏覽器的「閱讀模式」一樣，自動找出內文、上一章／下一章和目錄。維基文庫（`zh.wikisource.org`）已測試可用。

**通常讀得到的網站**：打開網頁不用登入就看得到整章文字，有「下一章」「下一頁」按鈕或目錄頁。UTF-8、GBK、Big5 編碼都會自動判斷。

**讀不到的網站**：

- 要登入或付費才看得到的章節
- 內容要等網頁裡的程式（JavaScript）執行後才出現的網站
- 會擋機器人檢查的網站
- 把文字加密成特殊字型的網站（念出來會是亂碼）

讀不到時畫面會顯示「找不到小說內文」，不會卡住。歡迎到 [Issues](../../issues) 回報網站，附上網址和遇到的情況。

## 常見問題

**按播放沒有聲音？**
Edge 自然語音需要網路。如果連續幾句都產生失敗，程式會自動改用瀏覽器語音，一分鐘後再試回 Edge 語音。也請確認電腦音量和設定裡的音量。

**聲音聽起來很像機器人？**
到設定的「聲音」選最上面「Edge 自然語音」那一組，例如 HsiaoChen 或 HsiaoYu。

**工作列顯示的是 Python 圖示？**
從原始碼執行，而且 Python 是從 Microsoft Store 安裝的話，Windows 會把它當成 Python 這個 App，工作列就會顯示 Python 的圖示。改用 Releases 的 exe，或自己打包 exe，就會顯示小說電台的圖示。

**想換成自己的圖示？**
在 `assets` 資料夾放 `icon-custom.png` 和 `icon-custom.ico`，程式會優先使用（這兩個檔案不會被 git 上傳）。

**進度存在哪裡？**
程式資料夾裡的 `.app-data`。用瀏覽器開的話，存在瀏覽器裡，兩邊的進度是分開的。

## 自己打包 exe

```bash
pip install pyinstaller edge-tts pywebview
pyinstaller --onefile --noconsole --name 小說電台 --icon assets/icon.ico --collect-data certifi app.py
```

打包好的 exe 在 `dist` 資料夾。把它跟 `reader.html`、`assets` 資料夾放在一起就能用。網頁畫面是從 `reader.html` 讀的，改畫面不用重新打包。

## 專案結構

| 檔案 | 說明 |
|---|---|
| `app.py` | 獨立視窗版的入口，用 pywebview 開視窗 |
| `novel_radio.py` | 本機伺服器：讀小說網頁、產生語音、轉送插圖 |
| `generic_reader.py` | 通用閱讀模式：從任何網頁找出內文、上一章／下一章、目錄 |
| `reader.html` | 程式畫面和播放器（HTML／CSS／JavaScript） |
| `assets/` | 圖示 |
| `啟動小說電台.bat` | 安裝套件並打開獨立視窗版 |
| `用瀏覽器開啟.bat` | 用瀏覽器開啟的版本 |

運作方式：程式在你電腦上開一個只有自己能連的小伺服器（`127.0.0.1`），由它去讀小說網頁、把句子交給 Edge 語音轉成音檔，畫面再一句一句播放。

## 使用須知

- 這是**個人閱讀輔助工具**，功能等同用瀏覽器打開網頁再請電腦念出來。它一次只讀你正在聽的那一頁，外加預先準備下一頁，每次讀取至少間隔 1 秒，**不提供整本下載**。
- 小說的著作權屬於作者和出版社。請只用來聽你有權閱讀的內容，並遵守各網站的使用條款。喜歡的作品，請支持正版。
- Edge 自然語音是透過 [edge-tts](https://github.com/rany2/edge-tts) 使用微軟的線上語音服務，並非微軟官方公開的服務，未來可能失效；失效時會自動改用瀏覽器語音。
